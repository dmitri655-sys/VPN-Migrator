# Сообщения о безопасности и границы доверия

Доверенными считаются управляющая машина, root обеих VPS, предварительно проверенные SSH host keys и исходная установка. Перенос с уже скомпрометированной VPS не очищает её код. SHA-256 не заменяет аудит бинарников. Не используйте утилиту как средство установки защиты.

Угрозы, которые учитывает MVP: подмена SSH-сервера (strict host key), shell injection через адрес/аргументы, запись за пределами staging из tar, links/devices, повреждённый или изменённый архив, перенос SQLite без WAL, частично завершённое размещение и утечка пароля через CLI/log.

Защита от конкурентных действий root, подмены файлов другим root между проверкой и rename, враждебных бинарников источника, отказа диска/ядра, компрометации OpenSSH, внешних правок systemd/firewall и независимых служб вне x-ui не заявляется. Блокировка предотвращает одновременные операции самой утилиты, а не вмешательство root.

Не публикуйте секреты в issue. Для отчёта подготовьте минимальный воспроизводимый пример на синтетических данных. Публичный upstream-репозиторий и приватный канал получения отчётов этим локальным артефактом не создаются; при публикации сопровождающий должен добавить свой контакт или GitHub private vulnerability reporting.
