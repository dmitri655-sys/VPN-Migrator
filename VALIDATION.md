# Проверка артефакта 0.2.0

Дата: 30 октября 2026.

Среды: Windows/Python 3.12.10 и локальная Ubuntu WSL/Python 3.14.4. Linux-проект копировался в `/tmp`, чтобы права DrvFS не подменяли POSIX-права. В обоих окружениях использован настоящий OpenSSL для временной PEM-пары.

* Windows `python -m unittest discover -s tests -v`: 43 теста, 42 прошли, 1 Linux symlink-тест пропущен.
* Ubuntu от root: 43 теста без пропусков. Python 3.9–3.13 на Linux отдельно не запускались.
* Linux synthetic smoke: настоящий export → stage → commit → rollback. Открытый WAL writer на источнике, независимый snapshot, TLS/OpenSSL, checksum, root ownership/0600, flock, rename и сохранение новых целевых данных после rollback.
* `python -m compileall -q vps_migrator tests tools`: успешная компиляция.
* Проверка синтаксиса всех Python-файлов в поставке по грамматике Python 3.9: пройдена. Это не запуск под всеми версиями Python.
* Запуск `--help` из проекта и из `.pyz`: проверен.
* Получение исходника SSH worker из ресурсов упакованного `.pyz`: проверено без сетевых подключений.
* CRC ZIP/PYZ и SHA-256 артефактов: проверены. Сборка использует фиксированные ZIP timestamps; повторная сборка должна давать те же байты при неизменных исходниках.

Содержательные тесты: живой WAL → независимый SQLite snapshot; повреждённая БД; TLS PEM-пара и неправильный ключ; небезопасные архивы; контрольные суммы; dry-run; подтверждение перед записью/запуском; preflight CPU/glibc/machine-id/порты/место; commit/rollback; сбои до и после rename; неуспешный health; запрет удаления резервов активной установки. В 0.2 добавлены env whitelist и rollback пятого корня, aggregate counts, client JSON, multi-node guard, отмена мастера и EOF.

Первый Linux smoke выявил ошибку manifest в 0.1: gettarinfo.mode содержал S_IFREG/S_IFDIR, а tar сериализовал только permission bits. В 0.2 mode нормализован перед записью manifest; повторный полный smoke прошёл. Независимая проверка нашла обход проверки EnvironmentFile через пробелы вокруг `=`: добавлен падающий регрессионный тест, затем исправление. Повторное review не выявило оставшихся существенных замечаний в согласованных границах.

Команды systemctl и факты о VPS в smoke подменены. Настоящие SSH-аутентификация/host key verification, запуск x-ui/Xray, внешние протоколы, runtime совместимость бинарников и реальный перенос между двумя VPS **не проверены**. Сценарий на одноразовых VPS — в `TESTING.md`. Нативный Windows-контроллер не поддерживается; используйте Linux/WSL.

Ни один рабочий сервер не изменялся. Публикации на GitHub, push и CI-запуска не было. Старые артефакты 0.1 сохранены для истории; новый перенос выполнять версией 0.2.
