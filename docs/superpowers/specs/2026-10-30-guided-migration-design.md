# VPS Migrator 0.2 — продолжение согласованного проекта

Основание: исходный запрос безопасного CLI/TUI и согласие продолжить после предложения добавить мастер, определение env-настроек и проверки данных. Стек остаётся Python 3.9+ standard library/OpenSSH. Реализацию выполняет основной агент в текущем проекте.

Результат: команда `wizard` на русском проводит через dry-run, staging, commit, activate. Каждый этап записи отдельно требует IP назначения, запуск дополнительно требует слова ЗАПУСТИТЬ. Пустой ответ останавливает сценарий, EOF/Ctrl+C не считается разрешением. Пароли спрашивает только OpenSSH. Сохраняется UUID для продолжения через существующие команды; мастер не хранит секреты или отдельный конфигурационный файл.

Совместимость: поддержать один root-owned `/etc/default/x-ui`, если unit явно ссылается на него (включая необязательный `-`), без shell execution. Разрешить лишь понятные SQLite-настройки с существующими стандартными путями. PostgreSQL, custom DB root, неизвестные переменные и внешние пути — понятный отказ, без вывода значений. Env-файл становится пятым корнем общей транзакции и отката. Не перезаписывать существующий env-файл на цели. Произвольные drop-ins и источники сертификатов не добавляются.

Данные: количества inbounds/users/settings и клиентов из JSON inbounds фиксируются именно из SQLite snapshot. После передачи и перед commit сравниваются со снимком; персональные данные не выводятся. Непустая таблица nodes блокирует перенос: распределённая установка вне MVP.

Проверки: RED→GREEN для мастера, env-файла/отката, повреждённого JSON и counts. Сохранить старые проверки WAL/архивов/подтверждений. Проверить Linux-ветки через имеющуюся локальную Ubuntu WSL; не называть mocked systemd настоящим переносом. Подготовить воспроизводимый интеграционный smoke-сценарий с настоящим SQLite, OpenSSL и файловыми операциями в временном Linux-каталоге.

Обсуждавшиеся альтернативы: заменить проект xui-mover (не сохраняет установку и допускает остановку источника); расширить наш проект на PostgreSQL (отложено, исходный кейс SQLite); развивать согласованную SQLite-основу (выбрано продолжением разговора).

Никаких изменений DNS/firewall/сети/старой службы; AWG2 не переносится. Автозапуск не включать. Ограничения реальных проверок указать в отчёте, старые артефакты 0.1 сохранить.
